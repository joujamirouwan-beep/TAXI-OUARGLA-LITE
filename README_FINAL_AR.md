# طاكسي ورقلة لايت V3.10.1 — مصدر مُعاد تجميعه

هذه إعادة تجميع إنقاذية من الملفات المتاحة في مكتبة المحادثة، وليست استعادة مؤكدة للأرشيف الأصلي.

## ما تم
- اعتماد مصدر V3.9 المتاح كأساس تاريخي لبعض الشاشات وملفات التشغيل وManifest.
- إضافة طبقة Core V3.10.1 (النماذج، الخدمات، المستودعات، التوجيه، الشاشات المرجعية، اختبارات، SQL V2.1 ووثائقه).
- إعداد pubspec يجمع اعتماديات المصدر التاريخي وخريطة OpenStreetMap.
- إنشاء ملفات Gradle تمهيدية مع تثبيت applicationId على `com.taxiouargla.lite`.

## تحذير مهم — لا ترفعها إلى Google Play بعد
- لم يتوفر Flutter/Dart/Android SDK في بيئة إعداد هذه الحزمة، لذلك لم يُشغّل pub get أو analyze أو test أو build.
- لا يتضمن الأرشيف Gradle Wrapper التنفيذي (`gradlew`, `gradlew.bat`, `gradle-wrapper.jar`) ولا مفتاح توقيع Play. ملف wrapper properties وحده لا يكفي للبناء.
- شاشة `main.dart` التاريخية من V3.9 لا تُثبت وحدها اكتمال توصيل واجهات Core الجديدة؛ يلزم دمج/اختبار نهائي للتوجيه.
- لم يتم الاتصال بـ Supabase الحي أو التحقق من المخطط المنشور. لا تشغّل SQL على قاعدة موجودة قبل نسخة احتياطية ومراجعة الفروقات.
- لا تدمج `taxi_ouargla_v3_10_1_patch.zip`؛ فهو يستخدم عقداً مختلفاً عن V2.1.

## ثوابت العمل المحفوظة
- الاسم: طاكسي ورقلة لايت.
- Android applicationId: `com.taxiouargla.lite`.
- حالات الرحلة الست: `searching`, `accepted`, `arrived`, `in_progress`, `completed`, `cancelled`.
- سائق واحد/رحلة نشطة واحدة كحد أقصى.
- لا يسمح للإدارة بإلغاء رحلة جارية أو مكتملة.
- السعر يتم الاتفاق عليه خارج التطبيق؛ لا محافظ ولا عمولات ولا دفع داخل التطبيق.

## لإكمال البناء محلياً
1. ثبّت Flutter stable وAndroid SDK وJDK متوافقاً.
2. من جذر المشروع نفّذ `flutter create . --platforms=android` لإنشاء ملفات المنصة والـwrapper الناقصة، مع مراجعة عدم استبدال Manifest الحالي.
3. نفّذ `flutter pub get`, ثم `flutter analyze` و`flutter test`. عالج كل الأخطاء قبل البناء.
4. راجع إعداد Supabase وRLS وRPC ومطابقة SQL V2.1، ثم اختبر على جهاز فعلي.
5. أنشئ إعداد توقيع release بمفتاح الرفع الأصلي، ثم `flutter build appbundle --release`.

هذه الحزمة مصدر عمل قابل للاستكمال، وليست APK أو AAB ولا شهادة جاهزية إنتاجية.
